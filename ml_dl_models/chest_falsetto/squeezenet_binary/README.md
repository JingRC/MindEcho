# SqueezeNet Binary Chest/Falsetto

This directory contains a lightweight binary training baseline for chest vs falsetto classification.

Files:
- train_squeezenet_binary.py: trains a 2-class SqueezeNet 1.1 model from mel.zip.
- artifacts/: stores the best checkpoint and training summary.
- reports/: reserved for later experiment notes.

Default command:

python train_squeezenet_binary.py
