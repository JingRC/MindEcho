# 主唱/伴唱功能手动实测步骤（第一轮）

适用版本：fix-from-47da9ae（2026-03-19）
目标：快速验证 A02/A03/B02/B03 的体验链路是否可用。

## 1. 测试前准备

1. 准备 3-5 首样本音频：

- 样本 A：单主唱、伴奏简单
- 样本 B：主唱 + 明显和声
- 样本 C：主唱 + 多人伴唱（嘈杂）

2. 每首建议时长 30s-90s，格式优先 wav/flac。

3. 确认输出目录可写，并预留 2GB 以上空间。

## 2. 功能链路实测（离线）

1. 打开纯人声入口，进入“主唱/伴唱设置”。
2. 开启 stage2，设置：

- 包含伴唱：开启
- 伴唱人数：先用 1，再测 2
- 主唱识别方式：先自动，再模板

3. 执行纯人声转化。
4. 转化完成后：

- 先点“试听分离结果”，验证主唱/伴唱/混听是否可切换且可播放
- 再点“进入一次性绘制”

5. 在一次性回放面板切换“轨道模式”：

- 主唱-only
- 伴唱-only（若存在伴唱轨道）
- 主唱+伴唱

6. 观察切换后重绘是否成功，回放是否连续可用。

- 是否出现异常（崩溃/卡死/无声/轨道错位）：
- 综合评分（1-5）：

## 4. 通过标准（第一轮）

1. 不崩溃：3/3 样本可完整跑通。
2. 可切换：一次性面板轨道模式切换成功率 100%。
3. 可试听：试听面板主唱/伴唱/混听均可播放。
4. 主观体验：至少 2/3 样本中，主唱-only 比主唱+伴唱更清晰。

## 5. 常见问题与判断

1. 切换轨道后重绘慢：属于当前实现预期（会重跑离线解析），记录耗时即可。
2. 模板模式不稳定：先回自动模式做对照，记录差异样本。
3. 伴唱人数 2 反而更差：保留样本，后续用于阈值和分轨策略调参。

## 6. 第二轮实测入口（实时链路 C02）

1. 打开“纯人声转化”，完成一次转化后，在完成弹窗中选择“进入实时分析（支持轨道切换）”。
2. 在实时分析面板顶部“轨道模式”中切换：

- 主唱-only
- 伴唱-only（若存在伴唱轨道）
- 主唱+伴唱

3. 点击“播放/暂停”，观察：

- 切换轨道后是否能自动重载并继续实时分析
- 时间轴与可视化是否继续正常跟随

4. 拖动进度条到中后段，重复切换轨道，观察是否出现：

- 无声
- 卡死
- 曲线不再更新

## 7. 通过标准（第二轮）

1. 轨道切换成功率：3/3 样本均可至少切换 3 次无崩溃。
2. 切换后可继续播放与绘制。
3. 进度条拖动后切换仍可恢复分析。

## 8. 建议测试节奏

1. 第一轮：离线链路（已可执行）。
2. 第二轮：实时链路 C02（本轮新增）。
3. 第三轮：拿问题样本做参数回归与性能采样。
