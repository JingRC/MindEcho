# MindEcho 使用指南

## 快速开始 ⚡

### 1. 检查系统要求
- Windows 10/11
- Python 3.7+
- 可用的麦克风设备

### 2. 安装依赖（三种方式）

**方式一: 自动安装脚本（推荐）**
```bash
# 双击运行
install_dependencies.bat
```

**方式二: 一键测试和安装**
```bash
python test_system.py
```

**方式三: 手动安装**
```bash
pip install sounddevice numpy scipy PyQt5
```

### 3. 启动应用
```bash
python run_mindecho.py
```

## 录音操作步骤 🎙️

### 基础录音流程
1. **启动应用** → 运行 `python run_mindecho.py`
2. **查看设备** → 点击"查询设备"确认麦克风可用
3. **设置参数** → 根据需要调整录音参数
4. **开始录音** → 点击"开始录音"按钮
5. **录音中** → 观察状态显示和录音时间
6. **停止录音** → 点击"停止录音"按钮
7. **查看文件** → 点击"打开文件夹"查看录音文件

### 参数设置详解

#### 采样率选择
- **8000 Hz**: 电话质量，文件小
- **16000 Hz**: 语音识别标准，推荐用于人声
- **22050 Hz**: 广播质量
- **44100 Hz**: CD质量，音乐录制标准
- **48000 Hz**: 专业音频标准

#### 声道设置
- **单声道**: 适合语音录制，文件较小
- **立体声**: 适合音乐录制，空间感更好

#### 数据类型
- **int16**: 标准WAV格式，兼容性好
- **float32**: 高精度，适合后期处理

## 故障解决 🔧

### 问题1: 无法启动录音
**症状**: 点击"开始录音"后显示"录音启动失败"

**解决方案**:
1. 检查麦克风连接
2. 确认Windows麦克风权限
3. 点击"查询设备"查看可用设备
4. 尝试重启应用程序

### 问题2: 模块导入失败
**症状**: 启动时出现"ImportError"或"ModuleNotFoundError"

**解决方案**:
1. 运行 `install_dependencies.bat`
2. 手动安装: `pip install sounddevice`
3. 检查Python环境是否正确

### 问题3: GUI启动失败
**症状**: 图形界面无法打开

**解决方案**:
1. 系统会自动切换到tkinter版本
2. 安装PyQt5: `pip install PyQt5`
3. 如果仍有问题，使用命令行版本

### 问题4: 录音质量差
**症状**: 录音文件有杂音或不清晰

**解决方案**:
1. 调整麦克风距离（15-30cm）
2. 选择更高的采样率
3. 检查环境噪音
4. 尝试不同的音频设备

### 问题5: 文件保存失败
**症状**: 录音完成但文件保存失败

**解决方案**:
1. 检查保存目录权限
2. 确保磁盘空间充足
3. 选择不同的保存目录
4. 检查文件名是否合法

## 高级功能 🚀

### 自定义保存目录
1. 点击"选择目录"按钮
2. 浏览并选择目标文件夹
3. 新的录音将保存到选定目录

### 设备选择
1. 点击"查询设备"查看所有音频设备
2. 记住需要使用的设备ID
3. 可在代码中指定特定设备

### 批量录音
1. 多次录音会自动按时间命名
2. 格式: `recording_YYYYMMDD_HHMMSS.wav`
3. 避免文件名冲突

## 性能建议 ⚡

### 内存优化
- 长时间录音会占用更多内存
- 建议录音时长不超过30分钟
- 录音完成后及时释放资源

### CPU优化
- 高采样率会增加CPU使用
- 录音时关闭不必要的程序
- 使用单声道减少处理负担

### 存储优化
- 44100Hz立体声约10MB/分钟
- 16000Hz单声道约2MB/分钟
- 定期清理录音文件
